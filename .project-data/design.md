# PureGraph Design

PureGraph builds, inspects, styles, and exports network diagrams from JSON, CSV, or TSV data.

The product should make graph import, node and edge editing, labeling, styling, selection, and export easy to understand. Graph parsing, document state, path handling, agent catalog, context, and handlers belong to the app.

The assistant contract should support graph context, loading/importing files, adding nodes and edges, changing labels or styles, removing elements, clearing the graph, and exporting without bypassing destructive-action review.
